## Why four repositories?

The platform is split into independently reviewable frontend and backend repositories and implemented through two delivery approaches:

- **Terraform-based AWS and EKS provisioning**
- **AWS CLI-driven CI/CD with CloudFormation integration**

The AWS CLI track uses CloudFormation integration for shared stack discovery; it is not presented as a standalone CloudFormation-template implementation. Together, the repositories demonstrate infrastructure automation, container delivery, secrets handling, and application rollout workflows.
